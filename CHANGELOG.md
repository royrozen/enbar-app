# Changelog

## [Unreleased]
Maintenance module (machine × maintenance-period tracking, QR-triggered checklists, parts catalog, fault reporting) — in progress on `feat/maintenance-tracking`, not yet merged to `main`. Phases 1-4 (+ revisions) done and approved; Phases 5-8 remain.
- **Phase 3-revision — anchor date picker (branch `fix/period-anchor-datepicker`, built and verified, pending Roy's review).** Corrected the yearly/triannual schedule-anchor UI shipped in Phase 3: the two unlabeled number inputs (day, month) read as a duplicate-field bug in the live app. Replaced with a single native date input (`ANCHOR_PICKER_YEAR = 2024`, a leap year, used only so Feb 29 is always selectable in the picker — the displayed year is discarded on every read, never stored). `machine_periods.anchor_day`'s CHECK loosened from 1-28 to 1-31 (the 1-28 range was copied from monthly's day-alone logic, which doesn't apply once day+month are picked together as a real calendar date) — `day_of_month`'s own 1-28 CHECK (monthly) is untouched. Added a February-29-in-a-non-leap-year shift to `compute_next_due_date`'s triannual/yearly branches (→ March 1), checked before the existing Saturday-shift, since `make_date()` throws for Feb 29 in a non-leap year. Verified via direct SQL calls (leap/non-leap/normal cases) and a live add-period click-through in both the mobile and desktop UI.
- **תחזוקת מכונות desktop layout + follow-ups (branch `fix/settings-desktop-layout`, merged to `main`).** Rebuilt the desktop (`lg:` / ≥1024px) layout of the Phase 3/4 machine-maintenance screen as a two-pane split console — machine roster on one side, full detail for the selected machine always visible on the other — replacing an initial 2-column card-grid concept that was rejected on review. Mobile layout/behavior unchanged (verified pixel-identical via screenshot diff). Along with the layout: tapping a part now expands full details inline (price, purchase date, supplier phone/SKU, larger photo — previously only visible via the edit form); the QR block was replaced with a small icon button (between edit and the active-toggle) that opens a print-ready popup (Enbar logo, machine number/name, QR) and auto-invokes the browser print dialog, instead of an always-rendered inline canvas; added a machine search box (name/number/location) above the list, reusing the existing `ManagerDashboard` search pattern. Also fixed a CSS specificity bug in `src/index.css`: `.manager-desktop .input`'s padding shorthand was overriding `select.input`'s reserved `padding-left`, letting the custom dropdown chevron overlap the last word in narrow selects (e.g. "הוספת מחזור טיפול") — distinct from the earlier Safari-only appearance:none bug below.
- **Phase 4 — parts catalog.** Added a `חלקים` tab to each machine's detail view: list/add/edit/deactivate covering all fields (store, price, purchase date, shelf location, descriptive quantity, photo). Photo upload reuses the existing report/exception-photo compression pattern. Fixed a Phase 1 gap found along the way: the `machine-parts` Storage bucket had no RLS policies, so uploads would have failed silently — added public-read + manager-insert/update policies matching the `machine_parts` table's own access rules.
- **Phase 3 — machine management + real data import.** Built the תחזוקת מכונות admin tab: machine list, add/edit/deactivate, per-machine period assignment (weekday/day-of-month/month+day anchor inputs matched to schedule kind), inline machine-owned task entry with cross-machine autocomplete, printable QR (encodes `machines.id`, never `machine_no`). Imported Roy's real 21-machine dataset (21 machines, 40 parts, 28 period assignments, 78 tasks) with placeholder anchors pending Roy's manual correction. Fixed two pre-existing bugs found during the work: the dev DB's periods catalog was missing the Phase 2-revision-2 fix, and `compute_next_due_date`'s triannual branch ignored its anchor_month/anchor_day inputs.
- **Phase 1 — schema + role model.** 11 new tables (`maintenance_periods`, `maintenance_tasks`, `machines`, `machine_periods`, `machine_period_tasks`, `maintenance_visits`, `machine_period_logs`, `machine_period_log_tasks`, `machine_parts`, `fault_reports`, `fault_report_parts`), all RLS `authenticated`-only. `profiles.role` extended with `factory_worker`/`platform_admin`; `profiles.employee_id` added; `employees.maintenance_access_enabled` added. New self-provisioning RLS `INSERT` policy lets a factory worker's own first OTP login create their `profiles` row, gated entirely in-database (no admin step, no service-role code). `compute_next_due_date()` (Saturday-shift rule) and `set_part_no()` (per-machine sequential numbering) helper functions/triggers. Two new public Storage buckets (`machine-parts`, `fault-reports`).
- **App-wide: `platform_admin` superadmin.** Widened from module-only to identical access to `factory_manager` everywhere in the app — 40 existing RLS policies across 16 tables (only their role predicate changed), plus the `/manager/settings` route guard. Standalone change, not scoped to the maintenance module.
- **Phase 2 — admin catalogs + employee access toggle.** Added a per-employee "גישה למודול תחזוקה" toggle to the existing employees tab (`ManagerSettings.jsx`), restricted to `factory_manager`/`platform_admin`.
- **Phase 2-revision.** Corrected Phase 2 per three later decisions: the periods catalog is no longer admin-manageable at all (fixed/seeded, 4 rows: שבועי, חודשי, תלת שנתי, אחת לשלוש שנים); added a new `triannual` schedule kind (3×/year, every 4 months) and renamed the old once-per-3-years cadence to disambiguate; restructured `/manager/settings` admin nav into one `תחזוקת מכונות` parent tab with `מכונות` (stub, Phase 3 builds it) and `משימות תחזוקה` (relocated, unchanged) sub-tabs.
- **Phase 2-revision-2.** Corrected the shipped seed data: deleted the `אחת לשלוש שנים` (once-per-3-years) row outright, restored a plain `שנתי` (once-a-year) row that had been accidentally dropped from the PRD. Final fixed catalog: שבועי / חודשי / שנתי / תלת שנתי.
- **Phase 2-revision-3.** Corrected the schema and UI per a third decision, after reviewing Roy's real machine/task CSV: tasks aren't a shared catalog, they're owned by a machine's period assignment. Dropped `maintenance_tasks` entirely (tagged `pre-task-model-revision`); `machine_period_tasks.task_id` → `task_name` (plain text); `machine_period_log_tasks.task_id` now points at `machine_period_tasks(id)` directly. Deleted the `משימות תחזוקה` tab/component — no standalone task-management screen exists anymore. `תחזוקת מכונות` collapsed from a parent-tab-with-sub-tabs into one flat tab (machines list only).

## [1.0.0] - 2026-09-09
Initial production baseline.
- Daily work reports (team lead submission + manager dashboard/review)
- Extras/change-order approval workflow (UI label "אישורי עבודה נוספת", internals `exception_logs`), including signed-document upload step
- Client / project / team-lead admin (deactivate-only, no hard delete)
- Self-hosted client e-signature flow (replaces prior SignWell integration)
- Lunch-ordering feature: QR self-order at time clock, phone-number lookup, 12:00 daily cutoff, monthly report for factory manager
